# Getting Started

DRAGON is a framework for designing, testing, and evaluating streaming data analysis workflows.

Unlike most stream learning frameworks, DRAGON focuses primarily on experimentation infrastructure rather than predictive models. The goal is to make it easy to prototype, compare, and analyze different monitoring, drift detection, and drift explanation workflows.

## Who Is DRAGON For?

DRAGON is intended for:

- Machine Learning practitioners
- Data Scientists
- Researchers working on monitoring and concept drift
- Users who are new to stream learning but familiar with batch machine learning

No prior knowledge of stream learning is required.

## The Typical Workflow

Most DRAGON workflows follow four conceptual stages:

1. Stream Generation
2. Memory Management and Processing
3. Drift Detection
4. Drift Analysis and Explanation

DRAGON provides reusable tools for each of these stages.

## Learning DRAGON

The recommended way to learn DRAGON is through the interactive tutorials.
