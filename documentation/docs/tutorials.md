# Tutorials

DRAGON is designed to be learned through interactive notebooks.

Rather than reading large amounts of documentation before writing code, users are encouraged to work through practical tutorials that introduce concepts incrementally.

## Tutorial Philosophy

The tutorials are:

- Interactive
- Step-by-step
- Feedback-driven
- Focused on experimentation

Each notebook introduces only a small number of concepts at a time and immediately applies them in practice.
